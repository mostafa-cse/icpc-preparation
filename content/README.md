# Competitive Programming Content & Problem Lists

This directory contains the curated problem lists, curricula, and algorithmic study materials that power the ICPC Preparation training program.

## Included Problem Sets

| File | Source / Platform | Description |
| :--- | :--- | :--- |
| [`CSES.md`](./CSES.md) | [CSES Problem Set](https://cses.fi/problemset/) | Essential foundational collection covering 300+ classic competitive programming problems. |
| [`USACO-Guide.md`](./USACO-Guide.md) | [USACO Guide](https://usaco.guide/) | Step-by-step training from Bronze to Platinum divisions. |
| [`cp-algo.md`](./cp-algo.md) | [CP-Algorithms](https://cp-algorithms.com/) | 89 topics across 12 algorithmic domains with practice problem links. |
| [`LightOJ.md`](./LightOJ.md) | [LightOJ](https://lightoj.com/) | Curated regional problem collection spanning classical DP, graph algorithms, and number theory. |
| [`Lougu-Training.md`](./Lougu-Training.md) | [Luogu](https://www.luogu.com.cn/) | Intensive structured curriculum covering fundamental algorithms through advanced data structures. |
| [`Cp-books.md`](./Cp-books.md) | Competitive Programming Classics | Curated exercises from classic CP literature (Halim, Laaksonen, Skiena). |
| [`acm.md`](./acm.md) | ICPC Regional & World Finals Archives | Past regional and preliminary competition problems for team contest simulation. |

## Data Structure in Application

These markdown files serve as the authoritative human-readable curriculum source. In the web application, their structured problem metadata (problem title, platform ID, difficulty rating, topic section, phase mapping, and deep-cut tags) is parsed and compiled into the high-speed in-memory database used by `frontend/script.js`.
